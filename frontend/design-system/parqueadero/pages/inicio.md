# Inicio (`/inicio`) — Bento cards

Inspiración: [Bento card UI / subscription analytics](https://dribbble.com/shots/24901695-Bento-card-UI-for-subscription-analytics-software-website-design) + ui-ux-pro-max **Bento Box Grid**.
Tokens: MASTER (azul Ops, sin purple).

## Layout

- Grid modular con tiles de tamaño variable
- KPIs 3 columnas (métricas con icono + acento suave)
- Fila principal: ocupación (wide) + ingresos (side) ≥900px
- Propietarios / tarifas en tiles full-width

## Visual

- Radius ~22px, sombra suave Apple-like
- Fondos con radial accent sutil (azul / naranja / teal)
- Sin lift exagerado; hover solo eleva sombra
- Captions limpias (sin franja mint)

## Motion

- ≤200ms; `prefers-reduced-motion` sin transform
